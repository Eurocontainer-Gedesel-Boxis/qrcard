# BOXIS · Eurocontainer · E=Gedesel — experiencia industrial premium

Landing corporativa de dos pantallas con diseño industrial, paneles de vidrio técnico, microinteracciones 3D y un visor Three.js de un conjunto contenerizado conceptual.

## Estructura
- `index.html`: página completa, responsive, dos secciones a pantalla completa y visor WebGL.
- `assets/eurocontainer-daylight-wide.webp`: fotografía diurna de Eurocontainer aportada para el proyecto.
- `assets/boxis-logo-from-supplied-image.png`: logotipo BOX Integration Systems recortado de la fotografía aportada.
- Los logotipos Eurocontainer y E=Gedesel se cargan desde recursos publicados por sus webs oficiales; si una web remota no permite cargar su imagen, permanece visible un nombre de marca alternativo.

## Visor 3D
Geometría procedural Three.js del conjunto: envolvente acústica, chapas nervadas, puertas, cierres, rejillas, silenciador, módulo superior y belly tank cuadrado de doble pared con refuerzos, tapas, respiraderos, drenaje, visor de nivel y placas. Incluye giro con ratón/táctil, zoom, giro automático y encuadre específico del depósito.

**Nota técnica:** es una visualización conceptual de alta fidelidad basada en la fotografía aportada y en descripciones públicas; no es un modelo CAD ni debe utilizarse como plano o especificación de fabricación. Para reproducir exactamente las dimensiones, piezas y serigrafía de una unidad real haría falta el modelo CAD/STEP y el manual gráfico oficial del fabricante.
